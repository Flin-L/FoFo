# FoFo AI 接手文档

## 项目定位

FoFo 是一个本地优先的个人工作台，用于管理目标、日程、待办、待阅文档、工作日志、备忘、番茄钟、饮水记录和产出热力图。

- 开发仓库：`F:\FoFo_development`
- 用户生产版：`F:\FoFo`
- GitHub 源仓库：`https://github.com/Flin-L/FoFo.git`
- 生产版包含个人数据，禁止覆盖数据文件或向外推送。

## 主要文件

- `index.html`：页面结构、顶部栏、弹窗和入口。
- `css/style.css`：主题、布局和组件样式。
- `js/app.js`：状态管理、事件绑定、本地持久化和主要交互。
- `js/components/calendar.js`：日历和节日/日程显示。
- `js/components/pomodoro.js`：番茄钟。
- `js/components/heatmap.js`：产出热力图。
- `js/components/export.js`：月度 Markdown 导出。
- `server.py`：本地服务和文件操作接口。
- `data/`、`documents/`、`exports/`：本地运行数据目录，开发仓库中不得放入真实个人数据。

## 启动方式

- 推荐：双击 `start.bat`，启动本地服务并打开浏览器；
- 备用：直接打开 `index.html`，使用浏览器 LocalStorage 模式。
- `start.bat` 是启动器：依次尝试 Python Launcher、PATH 中的 Python 和常见用户安装目录；找到后运行 `server.py`，否则回退为直接打开页面。

## FoFo AI 秘书

- 在“功能”菜单中打开“FoFo AI 秘书”；
- 未配置 API 时，可复制工作上下文并交给 ChatGPT 网页；
- 配置面板支持 OpenAI 和 DeepSeek 两种服务商；直连模式会把 Key 保存在当前浏览器，适合个人电脑；若提示 `Failed to fetch`，通常是浏览器跨域限制，应改用本地服务模式；
- 推荐新用户使用“本地服务模式”：
  1. 关闭正在运行的 FoFo 服务，打开 Windows 开始菜单，搜索“编辑系统环境变量”，进入“环境变量”；
  2. 在“用户变量”区域点击“新建”，使用 OpenAI 时填写变量名 `OPENAI_API_KEY`，使用 DeepSeek 时填写 `DEEPSEEK_API_KEY`，变量值粘贴对应 API Key；
  3. 连续点击“确定”，重新双击 `start.bat`，让新环境变量生效；
  4. 在 FoFo AI 配置中选择相同服务商和“本地服务模式”，保存后点击“测试连接”；
  5. 也可在 PowerShell 临时设置 `$env:OPENAI_API_KEY="你的Key"` 或 `$env:DEEPSEEK_API_KEY="你的Key"`，并在同一个窗口启动 `server.py`。
- 可选用 `FOFO_AI_PROVIDER`（`openai`/`deepseek`）和 `FOFO_AI_MODEL` 覆盖本地服务默认值；API Key 只由 `server.py` 读取，不要写入 `index.html`、README 或 Git。

## 后续交接规则

1. 所有开发只在 `F:\FoFo_development` 进行。
2. 未经用户授权，不修改版本号，不执行 Git 提交、标签或推送。
3. 未经用户授权，不同步到 `F:\FoFo`。
4. 同步时只覆盖程序文件，严禁覆盖用户数据。
5. 每次功能完成后保留简短改动记录，并先交由用户体验审阅。
6. **数据结构增量兼容**：绝对禁止对已有持久化数据（`workspace.json`、`reading_*.json`、`.FoFoAI/sessions.json`、`localStorage`）进行破坏性重命名或硬性删除；新增字段必须提供默认兜底值（Fallback），确保老数据平滑向上兼容。
7. **发布必带升级指引**：每次发布新版本，必须在 `README.md` 与 Release 说明中附带老用户平滑升级指引。
