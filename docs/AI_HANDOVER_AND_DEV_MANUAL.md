# FoFo AI 接手文档

## 项目定位

FoFo 是一个本地优先的个人工作台，用于管理目标、日程、待办、待阅文档、工作日志、备忘、番茄钟、饮水记录和产出热力图。

- 开发仓库：`F:\FoFo_development`
- 用户生产版：`F:\FoFo`
- GitHub 源仓库：`https://github.com/Flin-L/FoFo.git`
- 生产版包含个人数据，禁止覆盖数据文件或向外推送。

## 当前版本状态

### v1.0.0

首个正式版，建立三栏工作台、目标/待办、日程、待阅、日志、备忘、番茄钟、饮水记录、热力图、本地持久化和月报导出等基础能力。

### v1.1.0

加入中国大陆法定节假日、调休补班和农历日期支持。

## 主要文件

- `index.html`：页面结构、顶部栏、弹窗和入口。
- `css/style.css`：主题、布局和组件样式。
- `js/app.js`：状态管理、事件绑定、本地持久化和主要交互。
- `js/components/calendar.js`：日历和节日/日程显示。
- `js/components/pomodoro.js`：番茄钟。
- `js/components/heatmap.js`：产出热力图。
- `js/components/export.js`：月度 Markdown 导出。
- `server.py`：本地服务和文件操作接口。
- `data/`、`documents/`、`exports/`：本地运行数据目录，开发仓库中不得放入真实个人数据。

## 启动方式

- 推荐：双击 `start.bat`，启动本地服务并打开浏览器；
- 备用：直接打开 `index.html`，使用浏览器 LocalStorage 模式。

## 后续交接规则

1. 所有开发只在 `F:\FoFo_development` 进行。
2. 未经用户授权，不修改版本号，不执行 Git 提交、标签或推送。
3. 未经用户授权，不同步到 `F:\FoFo`。
4. 同步时只覆盖程序文件，严禁覆盖用户数据。
5. 每次功能完成后保留简短改动记录，并先交由用户体验审阅。
