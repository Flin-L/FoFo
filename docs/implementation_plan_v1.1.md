# FoFo 个人工作台 v1.1 优化与新特性实施方案 (基于 user_comment/commentV1.md)

针对用户在 `user_comment/commentV1.md` 中提出的反馈意见，本阶段完成了 8 项重大重构与体验优化。

---

## 优化要点与设计规划

### 1. 【UI 布局与主线区微调】月/周目标轮换式展示
- **现状问题**：左侧月目标和周目标列表过长时，将底部的【日程与重要节点】挤出可视区域。
- **优化方案**：
  - 将左侧上部设计为 **选项卡轮换式 (Tab Switcher)**：`[ 📌 本周重点 ]` 与 `[ 🎯 本月目标 ]`。
  - 默认展示日常高频关注的【本周重点】，点击可一键切换到【本月目标】。
  - 大幅压缩垂直高度，保证下方的 **【日程与重要节点】（迷你月历与当日事件）始终常驻在屏幕左下角**，无需滚动即可全局感知。

### 2. 【番茄钟体验升级】静音 + 桌面轻量浮窗提示
- **现状问题**：倒计时结束的声音打断工作节奏。
- **优化方案**：
  - 移除强制音频播放，改为**精致的浮窗 Toast 提醒**（右上角滑入，提示：“🍅 专注周期结束！已完成一次专注，稍作休息吧～”，带 5 秒进度条倒计时自动淡出，可手动关闭）。

### 3. 【健康打卡新增】每日饮水量记录 (目标 ≥ 1.5L)
- **设计位置**：在顶部中间番茄钟区域的底部紧凑展示。
- **功能细节**：
  - 显示今日饮水量与百分比进度：`🥤 750ml / 1500ml (50%)` + 动态水波/蓝条进度。
  - 提供快捷加水按钮：`+150ml`（小水杯）、`+250ml`（马克杯）、`+350ml`（大水壶），以及回退/清空按钮 `↺`。
  - 每日饮水记录按天自动持久化归档。

### 4. 【右侧板块重构】备忘公告栏 + 灵感备忘
- **结构重构**：将右侧备忘 Tab 改造为上下双层结构：
  - **上部：📌 备忘公告栏 (Bulletin Board)**：放置长期置顶的备忘原则、关键提醒、重要通知等，卡片式展示，支持添加与删除。
  - **下部：💡 灵感闪念 (Quick Scratchpad)**：继续保留灵感随手记，支持一键 `⚡ 转为今日待办`。

### 5. 【核心板块重构】原核心3件事 -> 【今日待阅】(Reading & References)
- **功能设计**：
  - 替换原今日 3 件事输入框，改为现代化卡片式【今日待阅】容器。
  - 点击 `+ 新增待阅` 弹出弹窗：
    1. 选择类型：`📄 本地文档`（支持 `.md`、`.doc`、`.docx`、`.pdf`）或 `🌐 网页链接`。
    2. 输入或选择：文档支持直接浏览选择或粘贴本地物理绝对路径；网页支持直接粘贴 URL。
    3. 输入自定义事项名（如“产品需求文档 PRD”、“技术架构规范”）。
  - **按天文件管理**：在 `F:\FoFo\documents` 目录下按日期自动生成归档（`reading_YYYY-MM-DD.json`）。
  - **一键唤起打开**：
    - 点击待阅卡片，前端调用服务端 `/api/open`。
    - 服务端调用 Windows 原生 `os.startfile(path)` 打开本地 Word/PDF/Markdown，或调用 `webbrowser.open(url)` 打开网页。
  - **排序与管理**：卡片支持 `↑` `↓` 调序及删除。

### 6. 【目标优先级管理】月度目标与周重点上下调序
- **优化方案**：在每个月目标和周任务条目右侧添加 `↑`（上移）和 `↓`（下移）按钮。点击即可实时与相邻项目交换位置并自动保存。

### 7. 【待办清单自动化】按 P0 > P1 > P2 优先级自动从高到低排序
- **优化方案**：
  - 排序权重规则：`P0 (紧急红)` > `P1 (重要黄)` > `P2 (普通蓝)`。
  - 新增待办或修改优先级后，系统自动重排并分组展示。

### 8. 【日程与重要节点】支持单日多事件标记
- **数据结构升级**：将原单个 `milestone: "文本"` 升级为 `milestones: [{ id, text }]` 数组结构，并兼容已有旧数据。
- **界面交互**：点击“+ 标记节点”可以为当天追加多个事件，当日事件列表中完整展示各项标记，均有独立删除按钮 `✕`。
