# FoFo 个人工作台 v1.0 初始实施方案 (MVP 阶段)

## 项目背景与核心诉求
用户目前依赖单一 Markdown 文档记录每个月的所有工作（月目标、周目标、每日工作流、待办事项、会议纪要、工作灵感）。随着内容累积，面临“长文本堆叠翻阅繁琐、目标容易被淹没、缺乏番茄钟计时联动、无法直观查看日历标记和类似 GitHub 的提交热力图”等痛点。

本项目旨在为用户打造一个**纯本地运行、轻量高效、结构清晰、极简美观**的个人工作管理面板，彻底解放单一长 Markdown 文档，同时保留纯文本的自由与安全感。

---

## 核心功能模块设计 (v1.0)

```
+-----------------------------------------------------------------------------------------+
|  顶部常驻条: [Logo FoFo]  |  本月进度条  |  🍅 番茄钟 (25:00 / 快捷启停)  |  GitHub 热力图  |
+-------------------+-------------------------------------------------+-------------------+
|  【规划与目标区】  |            【核心：今日工作流与任务清单】       |  【备忘与会议纪要】|
|                   |                                                 |                   |
| 🎯 本月目标 (OKR) |  📅 2026-09-17 星期四 (第38周)                  | 💡 闪念/灵感盒子   |
|   - 目标进度打卡  |  [+ 新增任务] (支持优先级 P0/P1/P2)              |   - 随手记随时存  |
|                   |  [ ] 核心任务 A  [🍅 启动专注]                   |                   |
| 📌 本周攻坚重点   |  [x] 已完成任务 B                               | 📝 会议纪要/深度记|
|   - 本周核心交付  |                                                 |   - 极简 Markdown |
|                   |  ---------------------------------------------  |     即时渲染输入  |
| 🗓️ 迷你日历与事件 |  🔄 每日微习惯 / 晨间三件事 (Daily Focus)       |                   |
|   - 关键节点与会议|                                                 | 📦 历史归档与导出 |
+-------------------+-------------------------------------------------+-------------------+
```

### 1. 顶部全局感知栏 (Header & Status)
- **时间与周期状态**：动态显示今日日期、周数、本月天数流逝进度。
- **内置番茄钟 (Pomodoro Focus)**：25分钟专注 / 5分钟短休 / 15分钟长休。支持一键绑定任务。
- **GitHub 风格贡献热力图 (Activity Heatmap)**：展示近 18~20 周活跃度，完成任务与番茄打卡点亮方块。

### 2. 左侧：长远目标与日历看板
- **月度目标卡片**：常驻视线左侧，支持设置完成度百分比滑块。
- **周目标看板**：承上启下的本周关键战役。
- **交互式日历**：按月浏览，支持标记关键里程碑。

### 3. 中间：今日工作流核心台
- **今日待办清单**：支持 P0/P1/P2 优先级，回车添加，完成彩花激励，一键开启专注。
- **每日焦点 (Today's Focus 3)**：每天核心 3 件事。

### 4. 右侧：轻量 Markdown 备忘与会议纪要
- **灵感闪念 (Scratchpad)**：临时想法捕捉，一键转为待办。
- **会议纪要与工作日志**：原生 Markdown 编辑与实时渲染预览，一键插入时间戳。

### 5. 数据管理与归档
- **纯本地数据持久化**：保存在 `f:\FoFo\data\workspace.json` 和浏览器 LocalStorage。
- **一键导出 Markdown**：点击“导出月报”生成标准 Markdown 文档保存至 `exports/`。
